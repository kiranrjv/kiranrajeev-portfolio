## 🌐 Free 1-Click Hosting Guide

### Option 1: GitHub Pages
1. Create a repository on [GitHub](https://github.com) named `kiran-rajeev-portfolio` (or `<your-username>.github.io`).
2. Push the files in this directory to the repository.
3. In GitHub, go to **Settings** ➔ **Pages** ➔ Set Branch to **main** and save.
4. Your website is live worldwide with HTTPS!

### Option 2: Netlify / Vercel
1. Navigate to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop this folder directly into the browser window.
3. It deploys instantly with a free SSL certificate and custom domain support.
